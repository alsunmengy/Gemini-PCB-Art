sources.csv                每张图：编号 / 尺寸 / 标题 / 作者 / 原帖链接 / 版权页

**编号与对照图上的数字一一对应**，先在 sheet 上挑号，再去目录按号取图。

- **PNG 256 色量化 + 保留 alpha**：白底合成时用 `Image.open(f).convert("RGBA")` 再贴到白画布，别直接丢 ffmpeg（会把白底变黑片）。
- `00_官方Q版_视频截帧_720x1280.jpg` 是 ZipZipPipe 原视频截帧（带背景），只作造型参考，不是纯立绘。
